## ⚖️ SECTION 1 — PSU vs PRIVATE: HONEST COMPARISON

| Parameter | Private MNC/Product | Top PSU (ONGC/NTPC/ISRO) | IT Services PSU (NIC/CDAC) |

| **Work-Life Balance** | Variable (often stressful) | Excellent — 9–5, no weekends | Excellent |

| **Ideal For** | Fast learners who want cutting-edge tech | People who value stability + national impact | People who want govt perks + IT work |

## 🗺️ SECTION 2 — RECRUITMENT PATHWAYS

### PATH 1: GATE Score (Most Common for Freshers)

<cite index="5-1">GATE score is valid for 3 years from date of result. Top PSUs accept GATE CS paper (CS01).</cite>

```
Step 1: Appear in GATE (CS/IT paper) — February each year
Step 2: GATE results declared — March each year
Step 3: Individual PSU notifications released — March to June
Step 4: Apply to each PSU separately (different portals, different deadlines)
Step 5: PSU shortlists based on GATE score (cutoff varies: ~600–750 marks)
Step 6: Interview / GD / Document verification
Step 7: Medical examination
Step 8: Joining
```

**GATE Score Cutoffs (Approximate 2026, General Category):**

| PSU Tier | Expected GATE Score | Approx GATE Rank |
|----------|--------------------|--------------------|
| ONGC, IOCL, NTPC, PGCIL | 700–780 | Top 200–500 |
| GAIL, BHEL, HAL, BPCL, HPCL | 650–720 | Top 500–1500 |
| BEL, ECIL, NALCO, NLC | 600–680 | Top 1500–4000 |
| SAIL, NMDC, CIL, GRSE | 550–650 | Top 4000–8000 |

### 14.1 — Preparation Timeline (Starting from Fresher Level)

```
MONTH 1–2: Foundation
  • Study GATE CS core topics (revise, don't start from scratch):
    - Data Structures & Algorithms (most important)
    - Operating Systems (your OS roadmap = direct advantage)
    - DBMS (your database roadmap = direct advantage)
    - Computer Networks (your NetOps360 = direct advantage)
    - Theory of Computation (TOC)
    - Compiler Design
    - Computer Organization & Architecture (COA)
    - Discrete Mathematics

MONTH 3–4: GATE Mock Tests + PSU-Specific Prep
  • Take GATE mock tests weekly (TARGET: 700+ score for top PSUs)
  • Study PSU-specific GD/Interview topics
  • Prepare "Why this PSU?" + domain knowledge for interviews
  • Start reading Employment News / PSU notification trackers

MONTH 5–6: Apply Phase
  • GATE appears in February — results in March
  • Monitor: psuguru.in, sarkariresult.com, projobalert.com
  • Apply to ALL relevant PSUs as notifications open (March–June)
  • Prepare for each PSU's specific interview format

PARALLEL TRACK: Direct Exam PSUs (No GATE)
  • ISRO ICRB: Engineering maths + CS core (separate pattern, apply directly)
  • DRDO CEPTAM: Two-tier exam (Gen.Intelligence + Technical)
  • NIC exam: CS fundamentals + aptitude
  • IBPS SO IT Officer: PK paper (CS/IT domain) + prelims
  • C-DAC: Direct application (no exam, interview-based for project roles)
  • NPCI: Direct application via npci.org.in + Naukri
```
